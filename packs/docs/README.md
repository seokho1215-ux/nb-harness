# Docs Pack

**Unique close-proof:** a docs change is "done" only when the **docs match the shipped behavior** — proven by
a review covering `matches-shipped-behavior` (not an aspirational version of the product).

`close_contract`: analytical `doc-accuracy` (light). Activates on `docs/`, `guides/`, README, CHANGELOG, and
structured doc formats (mdx/rst/adoc) — deliberately NOT every `.md`, so internal notes/handoffs don't pull
the pack.

> Status: `scaffold` — contract designed, not yet exercised end-to-end.
