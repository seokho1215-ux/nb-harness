# Debug Pack

**Unique close-proof:** a bug fix is "done" only when the **fix addresses the root cause, not the symptom** —
and since NB cannot machine-prove a root cause, this is honestly an **analytical-only** proof: a cross-family
review whose claims cover `cause-identified` and `fix-addresses-cause`, backed by before/after reproduction.

`close_contract`: analytical `root-cause` (standard). Usually declared (root-cause work is hard to detect by
path).
