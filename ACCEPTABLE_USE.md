# Acceptable Use

NB Harness includes security tooling (a red-team / attack module). Like any security tool (Nmap, Burp, Metasploit), it can be misused. By using NB you agree to the following.

## Allowed
- Run the security / attack module only against systems **you own** or are **explicitly authorized** to test.
- The **Sandbox Attack** mode is designed to run against a **copy you own** — cloning proves ownership.

## Not allowed
- Attacking, scanning, or probing systems you don't own or aren't authorized to test.
- Using NB to access, exfiltrate, or damage data that isn't yours.
- Removing or bypassing the safety pins (explicit consent, ownership proof, no real payment/mail/API, no destructive ops, secret redaction) in order to do any of the above.
